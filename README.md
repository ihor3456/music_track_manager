# Music Manager

**Опис проєкту**  
React-додаток для керування списком музичних треків з підтримкою:

- створення, редагування та видалення треків
- фільтрації та сортування
- пагінації
- завантаження аудіо (MP3/WAV) та відео (MP4/WebM)
- збереження стану в `localStorage`
- мобільної адаптації

## 🚀 Запуск

1. Розпакуйте архів
2. Встановіть залежності:
   npm install
3. Запустіть дев-сервер:
   npm start
